# SkyBridge Air Cargo

**A Web-Based Air Cargo Logistics Management Demo**

## 1. Project Overview

SkyBridge Air Cargo is a simple web-based logistics business application developed as part of an academic assignment. The website represents an air cargo logistics service that helps customers explore shipping services, track shipments, calculate estimated shipping costs, and submit enquiries.

The project demonstrates how web technologies can be used to present logistics services and provide basic interactive features for customers.

## 2. Objectives

- Develop a user-friendly website for an air cargo logistics business.
- Provide a shipment tracking interface using sample shipment data.
- Calculate estimated shipping charges based on route, shipment weight, and service type.
- Display logistics performance indicators through a dashboard.
- Provide a contact and enquiry form for customer interaction.

## 3. Key Features

- **Home:** Introduction to SkyBridge Air Cargo and its services.
- **About Us:** Overview of the business and its purpose.
- **Services:** Information about available air cargo logistics services.
- **Shipment Tracking:** Track sample shipments using demo tracking IDs.
- **Shipping Cost Calculator:** Calculate illustrative shipping costs based on origin, destination, weight, and service type.
- **Dashboard:** Displays sample logistics KPIs and shipment performance data.
- **Contact and Enquiry:** Provides contact details and an interactive enquiry form.
- **External Links:** Links to relevant aviation cargo and logistics resources.

## 4. Technologies Used

- **HTML5:** Website structure and content.
- **CSS3:** Styling, layout, and responsive design.
- **JavaScript:** Shipment tracking, shipping cost calculations, and form interactions.
- **GitHub:** Source code repository and version control.
- **GitHub Pages:** Website hosting and deployment.

## 6. How to Run the Project

1. Download or clone this repository.
2. Ensure `index.html` and `script.js` are in the same directory.
3. Open `index.html` in a web browser.
4. Explore the website sections and test the interactive features.

## 7. Sample Shipment Tracking IDs

- `SBC1025`

- `SBC5289`

These IDs use sample data for demonstration purposes only.

## 8. Dashboard Information

The dashboard presents illustrative logistics performance indicators, such as:

- Total shipments
- Delivered shipments
- Shipments in transit
- Delayed shipments
- On-time delivery percentage
- Customer rating

The figures are sample academic demonstration data and do not represent actual company operations.

## 9. Deployment

The website can be published using GitHub Pages:

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Click **Save** and wait for deployment.

GitHub will provide a public URL for accessing the website.

## 10. Limitations

- Shipment tracking uses predefined sample records rather than live logistics data.
- Shipping charges are illustrative estimates and are not actual carrier quotations.
- The enquiry form displays a demonstration confirmation and does not send emails to a server.
- The dashboard uses sample data and is not connected to a live logistics management system.

## 11. Future Enhancements

- Integrate real-time shipment tracking APIs.
- Connect the enquiry form to a backend system.
- Store shipment information in a database.
- Add customer login and shipment history.
- Integrate payment and booking functionality.
- Connect the dashboard to live operational data.

## 12. Conclusion

SkyBridge Air Cargo demonstrates how a basic web application can support customer-facing logistics activities. It combines a business website, shipment tracking, a shipping cost calculator, and a KPI dashboard in one interface. The project provides a foundation for understanding the practical application of web technologies in the logistics and supply chain management industry.

**Note:** This is an academic demonstration project and is not an operational air cargo booking or tracking platform.
